# Иллюстрации представлений

Созданы командой `py -m scripts.save_docs_images` по настоящим сигналам RadioML 2018.01A
(первый сигнал нужной пары (класс, SNR) из разбиения `data/splits/split.npz`).

| Файл | Что на нём |
|---|---|
| `overview_30dB.png` | 10 модуляций × 3 представления при SNR +30 дБ |
| `<модуляция>.png` | одна модуляция: строки — спектрограмма, скалограмма, созвездие; столбцы — SNR −10, 0, +10, +20, +30 дБ; оси в физических единицах |
| `raw/<модуляция>_<представление>.png` | само изображение 64×64 при +30 дБ, увеличенное в 4 раза (256×256), — то, что получит нейросеть |

Модуляции: OOK, 4ASK, BPSK, QPSK, 8PSK, 16QAM, 64QAM, AM-DSB-WC, FM, GMSK
(в именах файлов дефис заменён на `_`: `AM_DSB_WC`).

Как читать:

- **Спектрограмма** — по горизонтали время (1024 отсчёта), по вертикали частота
  от −0,5 до +0,5 частоты дискретизации, положительные частоты сверху; яркость — мощность в дБ.
- **Скалограмма** — по горизонтали время, по вертикали частота в логарифмическом масштабе
  (сверху 0,5, снизу 0,016 частоты дискретизации); знак частоты не различается.
- **Созвездие** — один отсчёт на символ (128 точек), I вправо, Q вверх, квадрат [−2,5; 2,5]
  после нормировки мощности к 1.

Цвета — палитра magma: тёмный — мало, светлый — много. Каждое изображение растянуто
по яркости отдельно, поэтому абсолютный уровень между картинками не сравним.
